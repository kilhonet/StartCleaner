## 概述

每次开机,聊天软件、更新助手以及各种服务都会跟着自动启动。单个看起来不大,积少成多就会拖慢开机速度并占用内存。

StartCleaner 从 **启动文件夹 · 注册表 · 计划任务 · 服务** 四个位置收集这些自动启动项,汇总成一个列表。选中不需要的项目并点击 **禁用**,从下次开机起它就不会再启动。这并不是删除,而只是关闭,之后点击一次 **启用** 就能原样恢复。

Windows 必需的基本项目已预先从列表中隐藏,因此不太会误关不该关闭的项目。

## 主要功能

- **一个列表统一管理** — 分散在启动文件夹、注册表、任务计划程序和服务中的自动启动项,集中在一处查看。
- **关闭而不删除** — 用 **禁用** 关闭,随时可以用 **启用** 恢复。
- **隐藏 Windows 基本项目** — 不能关闭的 Windows 组件不会出现在列表中。联网时会获取最新的隐藏项目列表。
- **易于辨认的名称** — 不显示文件名,而是显示程序的产品名称和图标。
- **彻底删除** — 已不再使用的程序留下的项目,可以先关闭再从列表中彻底删除。
- **查找信息** — 不认识的项目双击一下即可在网上查找。
- **保存列表** — 将当前所有自动启动项保存为文本文件。
- **深色模式** — 界面颜色跟随 Windows 应用模式(浅色 · 深色)。
- **9 种语言** — 韩语 · 英语 · 日语 · 中文 · 俄语 · 意大利语 · 法语 · 西班牙语 · 阿拉伯语。

## 使用方法

### 快速上手

1. 运行 StartCleaner,在管理员权限确认窗口中点击 **是**。
2. 开机时启动的项目会以 **程序** 和 **位置** 显示在列表中。
3. 单击想要关闭的项目,再点击下方的 **禁用**。
4. 该行会变成灰色,按钮变为 **启用**。从下次启动 Windows 起,该项目不会再运行。
5. 想重新开启时,单击同一行并点击 **启用**。

关闭的项目不会立刻从列表中消失,而是以灰色留在原处,方便马上撤销刚才的操作。

**位置** — 项目从哪里启动

| 位置 | 含义 |
|---|---|
| **启动文件夹** | 开始菜单"启动"文件夹中的快捷方式和程序(所有用户 · 当前用户) |
| **注册表** | 程序安装时登记为"登录时运行"的项目 |
| **计划任务** | 在任务计划程序中登记、按设定时间运行的任务(检查更新等) |
| **服务** | Windows 启动时自动启动的后台服务 |

### 这种情况怎么办

**想知道开机时有哪些东西一起启动**
直接运行 StartCleaner 即可。分散在四个位置的自动启动项会汇总到一个列表中,通过 **位置** 列就能知道它们登记在哪里。如果刚安装了新程序,按 **F5** 重新加载列表。

**不想让聊天软件或更新助手每次登录都启动**
在列表中单击该程序并点击 **禁用**。程序不会被删除,仍可照常使用,只是启动 Windows 时不再自动运行。需要时自己手动运行即可。**启动文件夹** 和 **注册表** 项目在任务管理器的 **启动应用** 选项卡中也同样显示为"已禁用"。

**想重新开启已关闭的项目**
勾选 **所有程序**,之前关闭的项目会以灰色行一起显示。单击该行并点击 **启用**,从下次开机起就会重新运行。

**想关闭在后台运行的更新计划任务**
**位置** 为 **计划任务** 的行就是登记在任务计划程序中的任务。浏览器和各种程序的更新检查大多在这里。选中想停止的任务并点击 **禁用**,即使到了设定时间也不会运行。

**不想让不需要的服务在开机时启动**
在 **服务** 行点击 **禁用**,该服务在 Windows 启动时不会启动,其他程序调用它也不会启动。点击 **启用** 则会改为随 Windows 启动自动运行。关闭服务前最好先确认它属于哪个程序 — 不认识的服务请按下面的方法先查一查。

**不知道这个项目是什么**
在列表中双击该行,浏览器会打开并显示该项目的相关信息。可以在关闭前确认它是做什么的程序。

**已卸载程序的自动启动项仍然残留**
程序已经卸载但列表中仍有它的名字时,先把该行改为 **禁用**,然后右键 → **删除**。在确认窗口中点击 **是**,该项目就会从列表中彻底删除。删除的项目无法恢复,请只删除确定不需要的项目。仍处于开启状态的项目不会出现 **删除** 菜单 — 先关闭并使用几天后再删除更为稳妥。

**想彻底删除服务**
只有改为 **禁用** 的服务才能 **删除**。正在运行的服务会先停止再删除。删除后会弹出"正在运行的服务将在重启后被完全移除"的提示,重启一次电脑即可彻底清理干净。

**所有程序中显示为灰色的服务**
**所有程序** 中也会以灰色行显示设置为仅在需要时启动的服务。对这类服务点击 **启用** 后,每次启动 Windows 都会自动启动它,因此如果不是您自己关闭的,请保持原样。

**想在整理之前记录当前状态**
在列表中右键 → **保存列表**,然后选择保存位置。包括列表中不显示的 Windows 基本项目在内,所有自动启动项都会保存为文本文件。可用于比较整理前后,或与另一台电脑对照。

**为什么列表中没有 Windows 基本项目**
音频、网络、安全等 Windows 运行所必需的服务和任务,从一开始就不在列表中显示。关闭它们可能导致 Windows 无法正常运行,因此 StartCleaner 干脆不让您碰它们。即使勾选 **所有程序**,这些项目也不会出现。

**用键盘浏览列表**
用 **↑** · **↓** 在行之间移动选择,列表会跟着滚动,让所选行始终可见。**F5** 重新加载列表。

**名称太长被截断时**
拖动窗口边缘把窗口拉宽,**程序** 列也会随之变宽。也可以拖动列标题之间的分界线,自行调整列宽。

**已在运行时再次运行**
StartCleaner 同时只运行一个。窗口已打开时再次运行不会启动新的副本,而是把已打开的窗口带到最前(如果已最小化则会还原)。

## 设置

没有需要设置的内容。StartCleaner 会自动跟随以下设置:

| 项目 | 跟随 |
|---|---|
| 语言 | Windows 区域设置(不支持的语言则使用英语) |
| 界面颜色 | Windows 应用模式(浅色 · 深色)— 即使在 StartCleaner 打开时更改也会立即跟随 |

## 系统要求

- Windows 10 · Windows 11(64 位)
- 管理员权限 — 更改自动启动项时需要。运行时会弹出确认窗口。
- 无需另外安装其他组件。
- 网络连接仅用于新版本提示和获取需隐藏的 Windows 基本项目列表。没有网络时也会使用内置列表照常运行。
