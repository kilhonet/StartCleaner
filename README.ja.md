## 概要

パソコンを起動するたびに、メッセンジャーやアップデート補助ツール、さまざまなサービスが一緒に立ち上がります。1 つ 1 つは小さくても、積み重なると起動が遅くなり、メモリを占有します。

StartCleaner は、こうした自動で立ち上がるものを **スタートアップ · レジストリ · タスク · サービス** の 4 か所から集め、1 つのリストにまとめて表示します。不要な項目を選んで **無効化** を押すと、次回の起動から立ち上がらなくなります。項目を削除するのではなく無効にするだけなので、あとから **有効化** を 1 回押せば元どおりに戻せます。

Windows が必要とする基本項目はあらかじめリストから隠してあるため、無効にしてはいけないものを誤って触ってしまう心配がほとんどありません。

## 主な機能

- **1 つのリストで管理** — スタートアップフォルダー、レジストリ、タスク スケジューラ、サービスに散らばった自動実行項目を 1 か所で確認できます。
- **削除せずに無効化** — **無効化** でオフにし、いつでも **有効化** で戻せます。
- **Windows の基本項目は非表示** — 無効にしてはいけない Windows コンポーネントはリストに表示されません。インターネットに接続されていれば、非表示にする項目の最新リストを取得します。
- **わかりやすい名前** — ファイル名ではなく、プログラムの製品名とアイコンで表示します。
- **完全に削除** — もう使っていないプログラムが残した項目は、無効化したあとリストから完全に削除できます。
- **情報を調べる** — 何かわからない項目は、ダブルクリック 1 回でウェブで調べられます。
- **リストを保存** — 現在の自動実行項目をすべてテキスト ファイルに保存します。
- **ダーク モード** — Windows のアプリ モード(ライト · ダーク)に合わせて画面の色が変わります。
- **9 言語** — 韓国語 · 英語 · 日本語 · 中国語 · ロシア語 · イタリア語 · フランス語 · スペイン語 · アラビア語。

## 使い方

### はじめての使い方

1. StartCleaner を実行し、管理者権限の確認画面で **はい** を押します。
2. 起動時に立ち上がる項目が **プログラム** と **場所** とともにリストに表示されます。
3. 無効にしたい項目を 1 回クリックし、下の **無効化** を押します。
4. その行が薄い表示に変わり、ボタンは **有効化** に変わります。次に Windows を起動したときから、その項目は実行されません。
5. 再び有効にしたいときは、同じ行をクリックして **有効化** を押します。

無効にした項目はすぐにはリストから消えず、薄い表示のまま同じ位置に残るので、今の操作をすぐに元に戻せます。

### 画面構成

| 要素 | 役割 |
|---|---|
| **ホーム** | 自動実行リストがある画面 |
| KILHO.net ロゴ | StartCleaner の紹介ページを開きます |
| **プログラム** 列 | プログラムのアイコンと名前(製品名があれば製品名) |
| **場所** 列 | その項目がどこに登録されているか — アイコンと名前 |
| 薄い行 | 無効になっている項目 |
| **全プログラム** | チェックすると、無効にした項目も含めてすべて表示します |
| **無効化** / **有効化** | 選んだ項目を無効または有効にします。項目を選ぶ前は薄く表示されます |
| 右クリック メニュー | **削除**(無効にした項目のみ) · **リストを保存** |

**場所** — どこから立ち上がる項目か

| 場所 | 意味 |
|---|---|
| **スタートアップ** | スタート メニューの「スタートアップ」フォルダーにあるショートカットとプログラム(すべてのユーザー · 現在のユーザー) |
| **レジストリ** | プログラムがインストール時に「サインイン時に実行」として登録した項目 |
| **タスク** | タスク スケジューラに登録され、決まったタイミングで実行されるタスク(アップデートの確認など) |
| **サービス** | Windows の起動時に自動で立ち上がるバックグラウンド サービス |

### こんなときは

**パソコンの起動時に何が一緒に立ち上がるのか知りたい**
StartCleaner を実行するだけです。4 か所に散らばった自動実行項目が 1 つのリストにまとまり、**場所** 列でどこに登録されているかがすぐにわかります。プログラムを新しくインストールした直後なら、**F5** でリストを読み込み直します。

**メッセンジャーやアップデート補助ツールがサインインのたびに立ち上がるのをやめたい**
リストでそのプログラムをクリックし、**無効化** を押します。プログラムは削除されず、これまでどおり使えます。ただ、Windows の起動時に自動で実行されなくなるだけです。必要なときに自分で起動してください。**スタートアップ** と **レジストリ** の項目は、タスク マネージャーの **スタートアップ アプリ** タブでも同じく「無効」と表示されます。

**無効にした項目を再び有効にしたい**
**全プログラム** をチェックすると、以前に無効にした項目が薄い行で一緒に表示されます。その行をクリックして **有効化** を押すと、次回の起動から再び実行されます。

**バックグラウンドで動くアップデートのタスクを止めたい**
**場所** が **タスク** の行は、タスク スケジューラに登録されたタスクです。ブラウザーやプログラムのアップデート確認の多くがここにあります。止めたいタスクを選んで **無効化** を押すと、決まった時刻になっても実行されません。

**不要なサービスを起動時に立ち上がらないようにしたい**
**サービス** の行で **無効化** を押すと、そのサービスは Windows の起動時に立ち上がらず、ほかのプログラムから呼び出されても起動しません。**有効化** を押すと、Windows の起動時に自動で立ち上がるように変わります。サービスは、どのプログラムが使っているものか確認してから無効にするのがおすすめです — 知らないサービスは、下の方法で先に調べてください。

**この項目が何なのかわからない**
リストでその行をダブルクリックすると、ブラウザーが開いてその項目に関する情報を表示します。無効にする前に、どんなプログラムなのかを確かめるのに使えます。

**アンインストールしたプログラムの自動実行項目が残っている**
プログラムを削除したのにリストに名前が残っている場合は、まずその行を **無効化** にしてから、右クリック → **削除** を押します。確認画面で **はい** を押すと、その項目はリストから完全に削除されます。削除した項目は元に戻せないので、確実に不要なものだけを削除してください。有効な項目には **削除** メニューが表示されません — まず無効にして数日使ってみてから削除すると安心です。

**サービスを完全に削除したい**
**削除** できるのは、**無効化** にしたサービスだけです。実行中のサービスは停止してから削除します。削除後に「実行中だったサービスは再起動後に完全に削除されます」という案内が表示されますが、パソコンを一度再起動すればきれいに片付きます。

**全プログラムで薄く表示されるサービス**
**全プログラム** には、必要なときだけ起動するよう設定されたサービスも薄い行で表示されます。こうしたサービスで **有効化** を押すと、Windows を起動するたびに自動で立ち上がるようになるので、自分で無効にしたものでなければそのままにしておいてください。

**整理する前に今の状態を残しておきたい**
リストで右クリック → **リストを保存** を押し、保存先を選びます。リストに表示されない Windows の基本項目も含め、すべての自動実行項目がテキスト ファイルに保存されます。整理の前後を比べたり、別のパソコンと見比べたりするときに使えます。

**Windows の基本項目がリストにない理由**
オーディオ、ネットワーク、セキュリティなど、Windows の動作に欠かせないサービスやタスクは、最初からリストに表示しません。無効にすると Windows が正常に動かなくなるおそれがあるため、StartCleaner ではそもそも触れないようにしています。**全プログラム** をチェックしても、これらの項目は表示されません。

**キーボードでリストを見る**
**↑** · **↓** で行を移動しながら選べます。選んだ行が常に見えるように、リストが追従してスクロールします。**F5** でリストを読み込み直します。

**名前が長くて途中で切れて見える**
ウィンドウの端をドラッグして広げると、**プログラム** 列も一緒に広がります。列見出しの境界をドラッグして、列幅を自分で調整することもできます。

**すでに実行中なのにもう一度実行した**
StartCleaner は 1 つしか実行されません。ウィンドウが開いている状態でもう一度実行しても新しく起動せず、すでに開いているウィンドウが前面に出てきます(最小化されていた場合は元に戻ります)。

## 設定

設定する項目はありません。StartCleaner は次のものに自動で従います。

| 項目 | 従うもの |
|---|---|
| 言語 | Windows の地域設定(対応していない言語の場合は英語) |
| 画面の色 | Windows のアプリ モード(ライト · ダーク)— StartCleaner を開いている間に変更しても、すぐに反映されます |

## 動作環境

- Windows 10 · Windows 11(64 ビット)
- 管理者権限 — 自動実行項目の変更に必要です。実行時に確認画面が表示されます。
- 別途インストールが必要なコンポーネントはありません。
- インターネット接続は、新バージョンのお知らせと、非表示にする Windows 基本項目のリストの取得にのみ使います。接続がなくても、内蔵のリストでそのまま動作します。

## アップデート

StartCleaner は自動でアップデート **しません**。起動時に新しいバージョンがあるかを確認してお知らせを表示し、**[はい]** を押すとダウンロード ページを開いてプログラムを終了します。新しいバージョンは社内での検証を経て手動で配布され、[StartCleaner のページ](https://kilho.net/startcleaner)でお知らせします。[アップデート ポリシーのお知らせ](https://en.kilho.net/archives/notice/2940)もご覧ください。
